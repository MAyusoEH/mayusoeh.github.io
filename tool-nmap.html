GENERADOR DE COMANDOS NMAP


Generador de líneas de comandos para escanear direcciones IP con NMAP en busca de puertos abiertos, vulnerabilidades, etc.




CHULETILLA:

• sudo → Ejecuta con privilegios de root (necesario para escaneos avanzados)
• -sS → Escaneo SYN (rápido, sigiloso y más difícil de detectar)
• -sC → Ejecuta scripts NSE predeterminados para detectar servicios y vulnerabilidades
• -sV → Detecta versión exacta de los servicios en los puertos abiertos
• -sU → Escanea puertos UDP (más lento pero importante para algunos servicios)
• -sT → Escaneo TCP Connect (completo pero más detectable por firewalls)
• --script=vuln → Ejecuta scripts que buscan vulnerabilidades conocidas
• --open → Muestra SOLO los puertos abiertos
• -n → Desactiva la resolución DNS (acelera mucho el escaneo)
• Puertos → Define número de puertos escanear
• Verbosidad → Define el detalle de la información mostrada
• Agresividad → Velocidad y ruido del escaneo (-T)
• --min-rate → Establece la velocidad mínima de paquetes por segundo

⚠️ Usa NMAP solo en entornos virtuales o con permiso explícito del propietario del sistema
