Una Dirección MAC es la DIRECCIÓN FÍSICA ÚNICA DE UNA INTERFAZ.

EJEMPLO DE DIRECCIÓN MAC:
```
08:00:27:8c:4d:3e
```

| Parte                                           | Octetos    | Ejemplo (MAC) | Descripción                         |
| ----------------------------------------------- | ---------- | ------------- | ----------------------------------- |
| **OUI**<br>(Organizationally Unique Identifier) | 1º, 2º, 3º | 08:00:27      | Identifica al fabricante (Vendor)   |
| **NIC** <br>(Network Interface Controller)      | 4º, 5º, 6º | 8c:4d:3e      | Identificador único del dispositivo |
